# Twitch Transparent Chat Overlay

Минималистичный, легковесный и полностью прозрачный оверлей чата Twitch поверх любых окон и игр. Не требует OAuth-авторизации, подключается напрямую по IRC/TLS через анонимный аккаунт Justinfan и не нагружает систему во время стрима.

## ⚠️ Важно: настройка игр для работы оверлея

Чтобы оверлей отображался поверх игры, переведите игру в настройках графики в режим **«В окне без рамки» (Borderless Windowed / Borderless Fullscreen)**.

В классическом полноэкранном режиме (**Exclusive Fullscreen**) видеокарта забирает вывод игры монопольно в обход оконного менеджера Windows (DWM), поэтому стандартные прозрачные окна поверх нее вывести невозможно.

## Возможности

* **Абсолютная прозрачность и сквозной режим**: окно удерживается на уровне `screen-saver`, оставаясь поверх borderless-окон. По нажатию Ctrl+Alt+F9 включается сквозной клик (Ignore Mouse Events) — оверлей перестает перехватывать курсор, скрывает шапку управления и не мешает геймплею.
* **Четкая читаемость в игре**: встроенная внешняя многовекторная обводка (`text-shadow`) предотвращает искажение шрифта и обеспечивает контраст даже на ярких игровых сценах.
* **Родные смайлы и бейджи**: рендеринг официальных бейджей Twitch (Broadcaster, Mod, VIP, Sub и др.) и смайлов по кодовым точкам Unicode без сдвига позиций.
* **Сторонние смайлы 7TV, BetterTTV и FrankerFaceZ**: глобальные и смайлы канала (ID канала берётся из `room-id`), поддержка анимированных и zero-width смайлов. Если включён SOCKS5, смайлы и их картинки загружаются через прокси, иначе напрямую.
* **Подсветка упоминаний и ответов** (можно отключить): сообщения с `@вашим_каналом` и ответы на ваши сообщения получают голубую заливку, голубую линию слева, короткую вспышку при появлении и выделенный `@ник`. Ник берётся из названия введённого канала, отдельных настроек не нужно. Подопция держит такие упоминания на экране вдвое дольше.
* **Маркировка наград за баллы канала**: автоматический перехват наград с текстовым вводом (`custom-reward-id`), тонкая золотая боковая линия и отображение иконки баллов канала. Если награда ещё и упоминает вас, линия остаётся золотой, а заливка становится голубой.
* **Синхронизация с модерацией**: когда модератор удаляет сообщение, банит или даёт таймаут пользователю, его сообщения сразу исчезают из оверлея. Очистка чата (`/clear`) очищает и оверлей. Работает по умолчанию, настраивать ничего не нужно.
* **Необязательные строки событий чата**: компактные однострочные уведомления о новых подписках, продлениях, подаренных подписках и рейдах. У каждого события своя галочка, по умолчанию все **выключены**. Массовая раздача подписок показывается одной строкой, а не по строке на каждого получателя.
* **Настройки в отдельном окне** с тремя вкладками: **Общие** (канал, язык, прокси, фильтры, автозапуск), **Оверлей** и **Виджет для OBS**. Окно оверлея не меняет размер, изменения внешнего вида видны на оверлее сразу, пока вы их настраиваете, а закрытие окна без сохранения возвращает сохранённый вид.
* **Виджет для OBS** (необязательный, по умолчанию выключен): чат как источник «Браузер» для OBS со своим размером и своими настройками внешнего вида, ссылкой в один клик, собственной кнопкой теста и поддержкой прокси для смайлов. См. раздел [Виджет для OBS](#виджет-для-obs-необязательный) ниже.
* **Тестовые сообщения**: кнопки в настройках последовательно показывают все сценарии (обычное сообщение, модератор, награда, `/me`, упоминание, ответ, награда + упоминание, длинное сообщение, все виды событий и сообщение, которое «модератор» удаляет) без подключения к чату. У оверлея и у виджета для OBS свои кнопки, поэтому на живую сцену ничего лишнего не попадёт.
* **Не пропадает при сворачивании окон**: у оверлея нет кнопки на панели задач и он не показывается в Alt+Tab, поэтому Win+D, «Свернуть все окна», Win+M и панель задач его не прячут. Управлять им нужно через иконку в трее и хоткей `Ctrl+Alt+F9`.
* **Кнопка «Сквозной режим»**: в шапке окна слева от «Настроек». Один клик включает сквозной режим (выйти из него можно хоткеем `Ctrl+Alt+F9` или через меню трея).
* **Запуск вместе с Windows**: необязательная галочка в настройках, по умолчанию выключена.
* **Только одна копия**: повторный запуск не открывает второй оверлей. Уже работающий выходит из сквозного режима, появляется и выходит на передний план.
* **Возврат потерянного окна**: если сохранённая позиция оказалась вне всех экранов (например, отключили монитор), оверлей запустится по центру основного монитора. Сохранённая позиция не перезаписывается, пока вы сами не сдвинете окно, поэтому после возвращения монитора окно встанет на прежнее место.
* **Иконка в трее**: левый или правый клик открывает меню: показать/скрыть оверлей, сквозной режим, настройки, выход.
* **Два языка интерфейса**: English (по умолчанию) и Русский, переключение в настройках без перезапуска.
* **Корректная обработка `/me`**: сообщения действия (`\x01ACTION ...\x01`) автоматически очищаются, окрашиваются цветом ника автора и не сбивают индексы смайлов.
* **Кастомная типографика**: выбор шрифтов (Inter, Montserrat, Roboto или системный UI), регулировка размера, фона плашки и выравнивания текста.
* **Защита от утечек памяти**: настраиваемое время скрытия сообщений, а также лимит сообщений в DOM (150 шт.) при отключенном таймере (`0 сек`), предотвращающий просадки FPS на длинных стримах.
* **Поддержка SOCKS5**: встроенный клиент с авторизацией по логину и паролю для обхода сетевых блокировок.
* **Фильтры чата**: скрытие команд (начинающихся с `!`) и игнор-лист ботов и отдельных пользователей (Nightbot, StreamElements и др.). Записи сверяются с логином пользователя и с отображаемым именем, поэтому ники не на латинице тоже работают.
* **Надежная сеть**: экспоненциальный backoff при сбоях, сторожевой таймер (Watchdog на 60 сек), отработка планового реконнекта Twitch (`RECONNECT`) и таймауты TLS/TCP. Состояние соединения показывает индикатор, а не сообщения в чате.

## Управление

| Элемент | Действие |
| :--- | :--- |
| **`Ctrl+Alt+F9`** | Переключение сквозного игрового режима (клик сквозь чат в игру) |
| **Правый нижний угол** | Маркер для изменения размера окна (в режиме настройки) |
| **Кнопка «Сквозной режим»** | В шапке окна, слева от «Настроек»: включает сквозной режим |
| **Кнопка «⚙ Настройки»** | Открывает окно настроек со вкладками «Общие», «Оверлей» и «Виджет для OBS» |
| **Кнопки «Тестовые сообщения»** | В настройках: одна для оверлея (вкладка «Оверлей») и одна для виджета (вкладка «Виджет для OBS») |
| **Иконка в трее** | Левый или правый клик открывает меню: показать/скрыть оверлей, сквозной режим, настройки, выход |

> Если `Ctrl+Alt+F9` уже занят другой программой, рядом с индикатором соединения появится жёлтый значок ⚠.

## Что стоит знать

* **Упоминания привязаны к названию канала.** Оверлей рассчитан на то, что вы смотрите свой чат, поэтому введённый канал одновременно является ником, который ищется в `@упоминаниях` и ответах. Если подключиться к чужому каналу, подсветка будет работать для владельца этого канала.
* **События чата приходят по обычному подключению.** Подписки, подарки и рейды показываются, когда Twitch присылает их в чат. Награды без текста и фолловы без авторизации недоступны, поэтому не показываются.
* **Сообщения, задержанные AutoMod,** не доставляются анонимному подключению, поэтому в оверлее их не будет изначально.
* **Нет кнопки на панели задач.** Оверлей не показывается на панели задач и в Alt+Tab. Чтобы скрыть или показать его, открыть настройки или выйти, используйте иконку в трее (левый или правый клик).
* **Виджет для OBS работает, пока запущено приложение.** Окно оверлея можно скрыть, виджет продолжит работать. Если закрыть приложение, источник «Браузер» опустеет и переподключится сам, когда приложение снова запустят.
* **Виджет доступен только на этом компьютере.** Сервер принимает подключения лишь с `127.0.0.1` и отклоняет всё остальное, поэтому OBS на другом компьютере его использовать не сможет.
* **Шрифты.** Inter, Montserrat и Roboto загружаются из Google Fonts; если сайт заблокирован или нет интернета, используется запасной шрифт. Системный шрифт берётся с того компьютера, где запущен OBS.

## Виджет для OBS (необязательный)

Кроме оверлея поверх игры приложение умеет показывать чат как **виджет для OBS**: он виден только на стриме, а не перед вами, и имеет свой размер и внешний вид. По умолчанию он **выключен**.

1. Откройте **Настройки → Виджет для OBS**, поставьте галочку **Включить виджет для OBS** и нажмите **Сохранить и подключиться**. Если порт `8769` занят, поменяйте его: приложение сообщит об этом.
2. Нажмите **Скопировать ссылку**.
3. В OBS добавьте источник **Браузер**, вставьте ссылку как URL и задайте нужные ширину и высоту. Виджет занимает весь источник, поэтому размер и пропорции задаются в OBS.
4. Нажмите **Тестовые сообщения (только виджет)**, чтобы увидеть в OBS все сценарии. Они не попадают в оверлей, а тест самого оверлея не попадает в OBS.

У виджета свои настройки внешнего вида (шрифт, размер, фон, анимация, направление, время жизни, события чата и подсветка упоминаний), а канал, прокси, игнор-лист и фильтр команд общие с оверлеем. Подсветка упоминаний по умолчанию **включена** в оверлее и **выключена** в виджете.

Заблокированные в вашем регионе смайлы продолжают работать: при включённом SOCKS5-прокси приложение само скачивает картинки и отдаёт их в OBS, поэтому OBS не обращается к этим серверам напрямую.

## Где хранятся настройки

Конфигурация, позиция и размеры окна не сбрасываются при перезапуске и сохраняются платформонезависимо через `electron-store`:

* **Windows**: `%APPDATA%\TwitchOverlay\config.json`  
  *(полный путь: `C:\Users\<Имя_Пользователя>\AppData\Roaming\TwitchOverlay\config.json`)*
* **Linux**: `~/.config/TwitchOverlay/config.json`
* **macOS**: `~/Library/Application Support/TwitchOverlay/config.json`

> При запуске из исходников через `npm start` папка называется `twitch-overlay`, а не `TwitchOverlay`.

## Стек технологий

* **Runtime**: Electron
* **Платформа**: Node.js
* **Сетевой уровень**: `tls`, `net`, `https`, `socks` (SOCKS5), парсер Twitch IRC v3 tags, API 7TV / BTTV / FFZ, локальный HTTP-сервер с SSE для виджета OBS
* **Хранилище данных**: `electron-store`
* **Сборка**: `electron-builder` (Portable)

## Установка и запуск в dev-режиме

1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/BuXaLo/TwitchTransparentChat.git
   cd TwitchTransparentChat
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите приложение:
   ```bash
   npm start
   ```

---

## Сборка Portable .exe

Для сборки исполняемого файла, не требующего установки Node.js:

1. Запустите команду сборщика:
   ```bash
   npm run dist
   ```

2. Готовый файл появится в папке `dist/`:
   ```text
   dist/TwitchOverlay 1.2.0.exe
   ```

> **Примечание**: При первом запуске исполняемого файла без платного цифрового сертификата Windows SmartScreen может показать синее окно с предупреждением. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
